1. Perfil → **Editar perfil**.
2. **Alterar foto** → escolha `foto-perfil-tiktok.png`.
3. **Nome** → `CR Automações` → Salvar.
4. **Nome de usuário** → uma das sugestões acima → Salvar.
5. **Bio** → cole uma das opções.

## Se não deixar trocar
- **Nome:** o TikTok só permite trocar **1 vez a cada 7 dias**.
- **Nome de usuário:** só **1 vez a cada 30 dias**, e precisa estar livre.
- **Foto/nome "em análise":** o TikTok revisa a mudança; pode levar algumas horas.
- **Conta muito nova ou em verificação:** às vezes o botão fica bloqueado nos primeiros dias.
- Atualize o app e tente pelo site **tiktok.com** (Perfil → Editar perfil).
