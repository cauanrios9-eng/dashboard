# CR Automações — repositório

- `painel.html`: painel (dashboard + CRM) entregue aos clientes de automação de WhatsApp.
- `conteudo/`: produção de conteúdo para Instagram e TikTok (plano, mídia, gerador, payloads do Metricool).
- `.claude/skills/`: skills `ig-*` (de github.com/sergebulaev/instagram-skills, licença MIT) + `metricool-agendador`.

Publicação: as skills `ig-*` mencionam Publora/`lib.publish`; neste projeto **não use isso**.
Publique pelo conector Metricool seguindo `.claude/skills/metricool-agendador/SKILL.md`.
Idioma do conteúdo: português do Brasil. Nunca invente números, resultados ou clientes.
